# data/

| 파일 | 설명 |
|---|---|
| `players.json` | 구단별 대표 타자 2명·투수 2명 설정. 수정해서 쓰세요. |
| `pitches_template.csv` | 투구 데이터 CSV 형식 예시(가짜 값 4줄) |

## 투구 데이터 CSV 형식 (투구 1개 = 1행)

| 컬럼 | 필수 | 설명 |
|---|---|---|
| `pitcher` | O | 투수 이름 (`players.json`의 이름과 같아야 함) |
| `batter` | O | 타자 이름 (`players.json`의 이름과 같아야 함) |
| `pitch_type` | O | `직구` / `변화구` (또는 FF, SL, CU, CH, 슬라이더, 커브, 포크 등 → 자동 분류) |
| `plate_x` | △ | 홈플레이트 통과 시 좌우 위치(ft). **포수 시점, 오른쪽이 +**, 0 = 중앙 |
| `plate_z` | △ | 통과 시 높이(ft) |
| `zone` | △ | `plate_x/plate_z`가 없을 때만 사용. 25분할 코드 `A1`~`E5` (알파벳=높이 위→아래, 숫자=포수 시점 왼→오 라고 가정. 출처 배치가 다르면 `kbo_heatmap/data.py`의 `zone_to_xy` 수정) |
| `is_strike` | O | 스트라이크 판정이면 1 (루킹·헛스윙·파울 포함), 볼이면 0. `Y/N`, `true/false`도 허용 |
| `pa_result` |  | 그 투구로 **타석이 끝났을 때만** 결과 기록, 아니면 빈칸. `1루타·2루타·3루타·홈런·아웃·삼진·병살·볼넷·사구·희생플라이…`. 없으면 타자 분석이 불가능 |

△ = `plate_x`+`plate_z` 또는 `zone` 중 하나는 필요합니다.

- `볼넷, 고의4구, 사구, 희생, 희생번트, 희생플라이`는 타수에서 제외하고, 그 외 값(아웃, 삼진, 병살 …)은 타수로 계산합니다.
- UTF-8(BOM 유무 무관)과 CP949(엑셀 한글 저장) CSV를 모두 읽습니다.
- 구종을 알 수 없거나 위치가 비어 있는 행은 건너뛰며, 건너뛴 개수를 경고로 알려줍니다.
